## 第四篇内容范围

`04-张量模型并行--Megatron-LM.md` 写成无需依赖来源文章的独立教程，内容包括：

1. 张量并行解决的问题以及与流水线并行的区别。
2. 线性层按列、按行切分时的 forward、backward、梯度归属和通信。
3. Megatron MLP 的列并行到行并行组合、逐步形状变化及通信量。
4. Multi-Head Attention 的 head/QKV 分片与输出投影。
5. 输入 Embedding、输出 Vocabulary Projection 的词表并行。
6. Vocabulary Parallel Cross Entropy 的全局最大值、指数和、目标 logit 与 backward。
7. TP、PP、DP、ZeRO/Distributed Optimizer 的组合与参数状态归属。
8. 本轮阅读讨论形成的 QA。

内容应保留来源的知识主线，同时修正不严谨的通信量口径；正文只陈述完整结论，阅读中的疑问集中放入 `QA`。

## 迁移规则

- 使用 Git 可识别的重命名方式迁移已有 Markdown 和图片，不改动图片二进制内容。
- 更新三篇已有笔记中的所有相对图片路径。
- 更新主题 `README.md` 中前四篇的链接与标题。
- 第四篇图片放入 `assets/04-张量模型并行--Megatron-LM/`，采用稳定、可读的英文文件名。
- 不创建插图索引。
- 不在正文使用“文章给出”“原文介绍”等依赖来源的口吻。

## 验收条件

- 四个 Markdown 文件名与批准的名称完全一致。
- 主题根目录只存在一个 `assets/` 配图入口，不再存在 `*.assets/` 目录。
- 所有 Markdown 图片引用均指向存在且有效的本地图片。
- 所有内部 Markdown 链接均可解析。
- 数学公式定界符成对，不含不可见控制字符或损坏的 LaTeX 命令。
- 第四篇包含本轮 QA，且没有插图索引和来源依赖式表述。
- Git 提交只包含本次笔记、命名、配图和索引重构，并推送至 `origin/main`。
